# Pattharapong Nuk Portfolio

Static personal portfolio with a downloadable resume. No GPT account or backend is required to view the website.

## Publish with GitHub Pages

1. Create a repository for this portfolio. GitHub Free supports Pages from public repositories; the uploaded source files will be visible too.
2. Upload the contents of this folder to the repository root, including index.html, style.css, app.js, icon.svg, resume.pdf, and .nojekyll. Extract the ZIP first; do not upload only the ZIP.
3. Open Settings → Pages → Build and deployment.
4. Select Deploy from a branch, choose your default branch and /(root), then Save.
5. Wait for the Pages deployment to finish. Use the live address shown under Settings → Pages.

The website uses relative asset paths, so it works with both account-level and repository-level GitHub Pages addresses. Google Fonts are optional; installed fallback fonts are used when unavailable.

Official guide: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site
